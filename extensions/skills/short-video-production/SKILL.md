# Short Video Production

## Overview

先产出高质量短视频母稿，再交给平台包装 skill 做最终成片包。

## When to Use

- 目标产物是 `15-90s` 的短视频
- 需要先锁定前 `1-3` 秒钩子、节奏和证据画面
- 需要给后续平台包装一个稳定的母版脚本

## Workflow

1. 明确这条短视频只解决一个核心承诺或一个核心问题。
2. 先写前 `1-3` 秒的钩子，至少给 `3` 个备选。
3. 把主体拆成 `2-6` 秒一个 beat，明确每个 beat 的任务：
   - 拉人留下
   - 给证据
   - 推进理解
   - 触发评论或收藏
4. 为每个 beat 指定画面来源：
   - A-roll
   - B-roll
   - 截图/录屏
   - 字卡/图表
   - 生成式资产
5. 标出第一处“强证据”必须出现的位置，默认不晚于前 `5-10` 秒。
6. 给出结尾动作：评论、收藏、关注、私信或跳转。

## Output Contract

最终输出至少包含：

- `working_title`
- `duration_target`
- `aspect_ratio`
- `hook_variants`
- `core_claim`
- `beat_sheet`
- `narration_script`
- `subtitle_source_script`
- `shot_list`
- `on_screen_text`
- `proof_inserts`
- `cta`
- `edit_notes`
- `assembly_strategy`
- `asset_gaps`

## Rules

- 一条短视频只打穿一个主张，不要塞多线叙事
- 先让观众留下，再解释细节
- 口播稿和字幕源必须保持同一主张与同一证据顺序
- 不要把字幕等同于口播全文；字幕负责节奏和强调
- 没有明确证据的句子，不要写成确定表达
- 这只是母稿，不负责最终平台标题、封面、首评和发布元数据
