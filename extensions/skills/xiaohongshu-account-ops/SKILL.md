# Xiaohongshu Account Ops

## Overview

把“小红书运营”从单条内容制作，提升为账号级的持续经营。

这个 skill 负责定义账号为什么值得关注、应该持续发什么、图文和短视频怎么分工、评论区怎么接、复盘看哪些信号。

## When to Use

- 新开一个小红书账号或调整现有账号定位
- 需要为小红书建立栏目矩阵和发布节奏
- 需要决定图文和短视频的内容配比
- 需要把评论区和复盘接入现有 media-ops workflow

## Workflow

1. 明确账号目标：
   - 增长
   - 搜索占位
   - 品牌建立
   - 咨询/私信转化
2. 定义账号定位：
   - 面向谁
   - 用户为什么要关注
   - 你提供什么稳定价值
3. 设计内容支柱：
   - 核心主题
   - 每个主题适合图文还是短视频
   - 证据或素材从哪里来
4. 设计栏目和系列位：
   - 可持续的系列名
   - 固定钩子模式
   - 收藏理由
   - 评论诱因
5. 定义发布节奏：
   - 每周图文数量
   - 每周短视频数量
   - 复盘频率
6. 设计评论区运营：
   - 置顶评论模板
   - 高频追问回复模板
   - 何时引导收藏、关注或私信
7. 定义复盘指标和实验池：
   - 收藏率
   - 评论质量
   - 主页访问
   - 关注转化
   - 线索质量

## Output Contract

最终输出至少包含：

- `account_positioning`
- `audience_segments`
- `content_pillars`
- `series_lanes`
- `note_video_mix`
- `search_capture_terms`
- `publishing_cadence`
- `comment_ops_plan`
- `north_star_metrics`
- `experiment_backlog`
- `monthly_review_rhythm`

## Operating Rules

- 小红书不要只看“发什么”，还要看“关注后还能连续得到什么”
- 图文和短视频不能只是同题复制，要有明确分工
- 图文优先承担“可保存、可搜索、可复看”的知识沉淀
- 短视频优先承担钩子、结果前置、情绪张力和快速认知建立
- 评论区不是售后区，而是第二增长现场，要设计追问和扩展回答
- 复盘不只看单条爆发，要看系列稳定性和账号长期定位是否越来越清晰
