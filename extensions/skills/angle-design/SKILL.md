# Angle Design

## Overview

选题决定做什么，角度设计决定这条内容为什么值得看、愿意存、愿意转。

## When to Use

- 已经选出主题，需要进一步收敛成单条作品
- 用户要提升作品竞争力和平台原生感
- 需要在制作前做“赢面判断”

## Workflow

1. 读取 `selected topic`、研究证据和 `benchmark deck`。
2. 生成 3-5 个候选角度，每个角度都明确：
   - 核心冲突
   - 新鲜度
   - 证据抓手
   - 情绪张力
   - 平台适配方式
3. 对候选角度打分：
   - `novelty`
   - `proof_strength`
   - `emotional_pull`
   - `platform_fit`
   - `save_share_potential`
   - `series_potential`
4. 选出主角度和备选角度。
5. 输出制作 brief，包括钩子假设、证明路径、禁区和 CTA。

## Output Template

- `primary_angle`
- `backup_angles`
- `hook_hypotheses`
- `proof_plan`
- `comment_prompt`
- `cta`
- `kill_reasons`

## Quality Gate

- 不要把“观点正确”误当成“作品有吸引力”
- 至少保留一个主角度和一个备选角度
- 如果没有足够证据支撑角度，明确降级或退回选题阶段
