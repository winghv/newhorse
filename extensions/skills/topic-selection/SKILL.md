# Topic Selection

## Overview

把“有什么能做”收敛成“下一步最值得做什么”。

## When to Use

- 已经有研究结果，需要排优先级
- 用户要选题、排期、做内容日历
- 需要把宽泛方向转成可制作 brief

## Workflow

1. 汇总候选题材，并结合对标拆解里的空白位和过饱和信号。
2. 对每个候选题打分：
   - 业务价值
   - 平台适配
   - 时效性
   - 空白位机会
   - 证据抓手
   - 制作成本
   - 风险
3. 选出优先级最高的题材。
4. 为每个入选题输出 brief，并给角度设计阶段留下清晰输入：
   - 核心观点
   - 目标受众
   - 平台
   - 钩子
   - 证明素材
   - CTA
   - 禁区
   - 为什么这个题此刻值得做

## Rules

- 必须给出取舍理由，不能只列一堆题目
- 不同平台可以复用主题，但不能复用完全相同的呈现方式
- 若高分题材缺少关键证据或素材，先标记为待补充
- 选题输出必须能让下游角度设计判断“靠什么赢”
