# Content Production

## Overview

从 brief 直接产出可执行内容包。

## When to Use

- 用户要制作短视频脚本、图文内容、社媒帖子
- 已经完成选题，需要进入具体产出阶段
- 需要把一个核心观点适配成多个平台版本

## Workflow

1. 读取 brief，确认平台、受众、目标动作和禁区。
2. 定义每个平台的内容形式：
   - 短视频
   - 图文笔记
   - 长帖/线程
   - 社区帖子
3. 生成平台版本：
   - 标题/钩子
   - 正文/脚本
   - 视觉或镜头提示
   - CTA
   - 标签建议
4. 生成素材清单和缺口说明。

## Production Rules

- 平台原生优先，不要跨平台复制粘贴
- 短视频先写前 3 秒，再写主体
- 任何事实性陈述都要能追溯到 brief 或研究资料
- 需要额外素材时直接列出来，不要藏在文字里
